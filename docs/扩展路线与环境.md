# 扩展路线与技术环境

本文在仓库根 [README.md](../README.md) 所述**当前可运行实现**之上，整理目标技术路线与环境注意点。日常命令以 [操作指引.md](操作指引.md) 为准；修改 `backend/actions/*.py` 后须**同时重启 Action 与 Rasa**。

---

## 1. 演进方向


| 阶段      | 说明+                                                                                                            |
| ------- | -------------------------------------------------------------------------------------------------------------- |
| **已实现** | Rasa 对话 + 表单借还/预约演示 + **Neo4j** 馆藏（`:LibraryBook`、`:BorrowRecord`）与书目图谱 + GraphRAG（NL2Cypher）+ Vue 前端 Webhook。 |
| **规划中** | **Ollama** 等本地推理替代或补充云端 LLM；与真实 OPAC/ILS 同步。                                                                   |


GraphRAG 相关代码主要在 `backend/actions/graph_rag.py`、`backend/kg_module/nl2cypher.py`、`prompt_templates.py`。

---

## 2. 技术栈（现状与规划）


| 层级    | 现状                                       | 规划扩展             |
| ----- | ---------------------------------------- | ---------------- |
| 对话引擎  | Rasa Open Source（`backend/`）             | 保持 Rasa 为编排核心    |
| 书目与流通 | Neo4j（`neo4j_library_store.py`）          | 与 OPAC/ILS 或增量同步 |
| 图数据库  | Neo4j（书目 + 馆藏合一）                         | 集群、备份与读写分离（生产）   |
| 推理    | DeepSeek（数据咨询、推荐阅读、兜底等，见 `.env.example`） | Ollama + 自选量化模型  |
| 前端    | `front/lib_agent_vue`（Vite + Vue 3）      | 同左               |


容器编排：`deploy/docker-compose.yml`（Neo4j + Rasa + Action；密钥见根目录 `.env`）。

## 3. 目录与模块（节选）

```text
library_agent/
├── backend/                 # Rasa：actions、data、kg_module、config、启动脚本
├── front/lib_agent_vue/     # Vue 聊天页
├── docs/                    # 文档（本索引所在目录）
├── deploy/                  # Docker Compose
└── sql/                     # 可选 SQL 注释脚本（非运行必需）
```

规划中的可选布局（避免与 `data/` 训练数据混淆）可将 Neo4j 客户端、多 LLM 适配等放在 `backend/actions/` 或独立包中，按需引入。

---

## 4. Python 与依赖

- 推荐 **Python 3.10.x**（与 Rasa 3.6.x 兼容；勿用未官方支持的 3.13 等）。
- 隔离环境：**conda** 或 **venv**，步骤见 [操作指引.md](操作指引.md)。


| 类别     | 包名（示例）            | 用途                  |
| ------ | ----------------- | ------------------- |
| 对话     | `rasa`、`rasa-sdk` | NLU/Core、自定义 Action |
| 图数据库   | `neo4j`           | Cypher 驱动           |
| HTTP   | `requests`        | DeepSeek、维基等        |
| 中文 NLU | `jieba`           | `config.yml` 已引用    |


安装后**不要随意升级** Rasa 锁定的传递依赖，以免训练或推理异常。

---

## 5. 兼容性与算力

- **Rasa 3.x**：依赖树较深，升级单包前建议在虚拟环境中回归 `rasa train` 与一轮完整对话。
- **本地大模型**：GPU 需匹配驱动；CPU 量化可跑通原型，延迟需预期。
- **Neo4j**：演示可用 Docker；生产注意备份与连接池；Action 多实例时共用图库后端。
