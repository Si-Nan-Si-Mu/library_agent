### 功能一览（当前演示行为）

| 能力 | 说明 |
|------|------|
| 借书 | 表单收集书名、索书号；确认后由 SQLite 判定在架并更新借阅状态 |
| 还书 | 同上；对已借出记录办理归还 |
| 空间预约 | 收集空间类型与时段；**演示规则**判定成功与否（未接预约系统） |
| 借阅指引 / 数据咨询 | 固定话术；数据类不编造统计数字 |
| 推荐阅读 | 按主题槽位查询 SQLite 在架书名（演示，非馆藏承诺） |
| FAQ | 检索意图 `faq/*`（开闭馆、借阅规则、静音区、Wi‑Fi、占座规则等） |

自定义动作见 `backend/actions/actions.py`。接入 OPAC、预约系统或报表 API 时需替换为真实调用。

## 五、产品与合规（非代码但必须完善）

| 项 | 状态 | 说明 |
|------|------|------|
| 话术免责声明（演示非馆藏承诺） | ✅ | 见下文及 `domain` 中相关 utter |
| 身份与隐私、登录与会话策略 | ⬜ | PRD / 法务 |
| 无障碍与多语言 | ⬜ | 视服务对象 |
| 监控与告警（意图、表单放弃率、API 失败） | ⬜ | 运维 |

1. **身份与隐私**：借还、预约通常需读者身份；对话中是否登录、是否仅绑定会话 ID，需在 PRD 中定义，并符合个人信息保护要求。
2. **免责声明**：推荐与「数据解读」不构成专业建议；医学类话术已全部替换为馆方适用表述。**演示话术**：推荐与数据类回复仅为演示，不构成馆藏或统计承诺；生产环境须对接真实业务系统、权限与审计，并采用馆方用户须知与免责声明。
3. **无障碍与多语言**：视服务对象增加简易模式或英文槽位说明。
4. **监控**：对意图分布、表单放弃率、API 失败率做日志与告警。
